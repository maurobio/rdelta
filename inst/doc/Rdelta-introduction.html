Introduction

Overview of the DELTA System

The DELTA (DEscription Language for TAxonomy) system is a flexible data format for coding taxonomic descriptions and computer processing, allowing the construction of both conventional and interactive identification keys, diagnoses, natural-language descriptions, as well as data analysis. Developed by Mike Dallwitz and colleagues at CSIRO starting in 1979 (Dallwitz 1980, Dallwitz et al. 1993), it has been a recognized standard of Biodiversity Information Standards (TDWG) since 1986.

The DELTA Format

The format is designed to be a flexible and powerful way to capture descriptive data for a wide variety of organisms, from viruses and fungi to several groups of plants and animals. This encoding is versatile enough to be the primary way of recording data, even without immediate plans for computer processing (Pankhurst 1986, Askevold & O’Brien 1994, Colemen et al. 2010).

The DELTA System and its Programs

The DELTA System is an integrated set of programs built around this format (Dallwitz et al. 1993). These programs allow to generate a variety of outputs from the same coded dataset:

  • Natural-Language Descriptions: The CONFOR program can convert the coded data into high-quality, formatted natural-language descriptions, with control over sentence structure and the inclusion of important attributes. This can be used to generate descriptions for taxonomic monographs and floras automatically.

  • Identification Keys: The KEY program (Dallwitz 1974) generates conventional (printed) identification keys. It can tailor keys for specific purposes by adjusting weights for character reliability and selecting subsets of characters and taxa.

  • Interactive Identification: The INTKEY program (Dallwitz 1993) enables powerful interactive identification and information retrieval, allowing users to identify specimens by entering attributes in any order, handling errors and uncertainty, and directly processing numeric values. It is considered a key feature of the DELTA system.

  • Diagnoses: The system can generate diagnostic descriptions, which are sets of characters that distinguish a particular taxon from others.

  • Data Analysis: The system can convert data into formats required for phylogenetic and phenetic analysis programs, and calculate distance matrices for clustering and ordination analysis.

Over time, the DELTA software has been updated, including Open Delta, a newer Java-based implementation developed by the Atlas of Living Australia, and Free Delta, a Lazarus/Free Pascal implementation developed by The Free Delta Project, both of which runs on MS-Windows, MacOSX, and GNU/Linux.

The RDelta Library

None of the existing R packages for handling ans processing taxonomic data provide access to DELTA-coded files. The aim of the RDelta package is to fill this gap in the R ecosystem by providing a comprehensive set of functions, not only for reading and writing DELTA data, but for generating several products (natural-language descriptions, identification keys, distance matrices) as well.

This vignette documents the test programs and utilities developed for the RDelta package. These programs demonstrate various features of the package and can serve as examples for developers and advanced users.

The following test programs are included:

  1. test_RDelta.R - Interactive test program for RDelta functionality
  2. identification.R - Simple identification function using RDelta

1. Interactive Test Program (test_RDelta.R)

This program provides an interactive menu-driven interface for testing RDelta package functions. It allows users to:

  • Display character lists and retrieve character information
  • Display item lists and retrieve item information
  • Test item/character-value matching
  • Run identification tests
  • Display specifications and full package information

library(RDelta)

#--- Get command line arguments ----------------------------------------------
# This works in both interactive and non-interactive modes
get_args <- function() {
  # Get all command line arguments
  args <- commandArgs(trailingOnly = TRUE)
  
  # If running interactively and no arguments were provided,
  # prompt the user for file names
  if (interactive() && length(args) == 0) {
    cat("\nNo command-line arguments provided.\n")
    cat("Please enter file names (or press Enter to use defaults):\n\n")
    
    chars <- readline(prompt = "Characters file [chars]: ")
    if (chars == "") chars <- "chars"
    
    items <- readline(prompt = "Items file [items]: ")
    if (items == "") items <- "items"
    
    specs <- readline(prompt = "Specifications file [specs] (optional): ")
    if (specs == "") specs <- NULL
    
    return(list(chars = chars, items = items, specs = specs))
  }
  
  # Non-interactive mode or arguments provided
  if (length(args) >= 2) {
    chars <- args[1]
    items <- args[2]
    specs <- if (length(args) >= 3) args[3] else NULL
  } else {
    # Default files
    chars <- "chars"
    items <- "items"
    specs <- "specs"
  }
  
  return(list(chars = chars, items = items, specs = specs))
}

2. Identification Function (identification.R)

This module demonstrates a simplified identification system using RDelta. It allows users to identify taxa by successively comparing observed character values against item descriptions stored in DELTA files.

Source Code


message_identification <- function() {
  cat("\nIDENTIFICATION\n")
  cat("This function demonstrates the possibility using RDelta package for taxa\n")
  cat("identification.\n")
  cat("In this example, the identification process has been simplified a lot.\n")
  cat("It is based on successive comparisons between observed characters values,\n")
  cat("and the items descriptions stored in the Delta files.\n")
  cat("Advanced features, such as values combinations, implicit values, dependant\n")
  cat("characters are not implemented. There is no characters selection during\n")
  cat("identification (like the 'best' command in Intkey).\n")
  cat("Of course, the user interface is very simple, and should be improved in\n")
  cat("a public release.\n\n")
  cat("Usage :\n")
  cat("To make an identification, you should have a printed version of characters\n")
  cat("description (Delta chars file).\n")
  cat("Select a character and a value according to the taxon you want to identify.\n")
  cat("After each selection, the program displays all characters values already\n")
  cat("selected, and the list of remaining taxa.\n")
  cat("To cancel a previous selected character, select it again, and input the\n")
  cat("UNKNOWN value (-1). You can also modify a previously selected value.\n\n")
}

identification <- function(delta) {
  #----- Initialisation -----
  nbval <- RDelta::get_chars_nb(delta)
  nbitm <- RDelta::get_items_nb(delta)
  
  tabval <- rep(NA, nbval)
  tabitm <- rep(1, nbitm)
  
  message_identification()
  
  #----- User input and search matching items -----
  while (TRUE) {
    #--- Input character number and value
    cat("Select a character describing the item to identify :\n")
    cat("  Enter character number (0=exit) : ")
    charnum <- as.integer(readline())
    
    if (is.na(charnum) || charnum == 0) break
    
    if (charnum < 1 || charnum > nbval) {
      cat("  Invalid character number\n")
      next
    }
    
    cat("  Enter character state/value (-1=unknown) : ")
    charval <- as.numeric(readline())
    
    if (is.na(charval)) {
      cat("  Invalid value, please enter a number\n")
      next
    }
    
    #--- Stores value
    tabval[charnum] <- if (charval == -1) NA else charval
    
    #--- Update items table considering selected values
    for (i in 1:nbitm) {
      for (j in 1:nbval) {
        if (is.na(tabval[j])) {
          tabitm[i] <- 1
        } else {
          tabitm[i] <- as.integer(RDelta::matches(delta, i, j, tabval[j]))
        }
        if (tabitm[i] == 0) break
      }
    }
    
    #--- Displays selected characters and values, and remaining items list
    cat("\nCHARACTERS SELECTION\n")
    for (j in 1:nbval) {
      if (!is.na(tabval[j])) {
        cat(j, ". ", RDelta::get_char_feature(delta, j), "\n", sep = "")
        cat("    state/value : ", tabval[j], sep = "")
        
        if (RDelta::get_char_type(delta, j) == 2) {
          cat(" - ", RDelta::get_state(delta, j, as.integer(tabval[j])), "\n", sep = "")
        } else if (RDelta::get_char_type(delta, j) == 4) {
          cat(" ", RDelta::get_char_unit(delta, j), "\n", sep = "")
        } else {
          cat("\n")
        }
      }
    }
    
    cat("ITEMS REMAINING\n")
    for (i in 1:nbitm) {
      if (tabitm[i] == 1) {
        cat(delta$get_item_name(i), "\n")
      }
    }
    cat("\n")
  }
}
